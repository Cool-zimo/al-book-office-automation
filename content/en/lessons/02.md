# 02 Walking Directories: `os.walk` / `pathlib.iterdir`, Filtering by Extension

> This lesson covers step 1 of batch processing: how to "find" files in a directory and pick only the ones we want.

## Two Main Approaches

The standard library gives us two tools for traversal: the classic `os.walk` and the Python 3.4+ recommended `pathlib`. **Prefer `pathlib`** — its objects come with many convenient methods.

### Approach 1: `os.walk` (recursive)

```python
import os
for root, dirs, files in os.walk("."):
    for name in files:
        print(os.path.join(root, name))
```

`os.walk` **recurses** into every subdirectory. `root` is the current directory path, `files` is the list of filenames there.

### Approach 2: `pathlib` (recommended)

```python
from pathlib import Path
for p in Path(".").iterdir():
    if p.is_file():
        print(p.name, p.suffix)
```

`Path.iterdir()` traverses **one level only** (non-recursive). For recursion use `Path.rglob("*.pdf")` or `Path.glob("**/*.pdf")`.

## Filtering by Extension

Just the PDFs:

```python
from pathlib import Path
pdfs = [p for p in Path(".").iterdir() if p.suffix == ".pdf"]
# or more flexibly
pdfs = list(Path(".").glob("*.pdf"))
```

`glob` supports wildcards; `*.pdf` matches all PDFs in the current directory; `**/*.pdf` matches recursively.

## Crash Scene

```python
# Wanted every .xlsx in all subdirs, wrote:
for p in Path(".").iterdir():
    if p.suffix == ".xlsx":
        print(p)
# Result: only found xlsx in the current dir, missed every subdir
```

**Consequence**: missed files. Because `iterdir()` is not recursive. Use `rglob("*.xlsx")` for recursion. This is the most common batch-processing bug — **the script finishes, you think you're done, but only half the work ran**.

## Useful `pathlib` Attributes

| Attribute/method | Purpose |
|---|---|
| `p.name` | Full filename `report.pdf` |
| `p.stem` | Name without suffix `report` |
| `p.suffix` | Extension `.pdf` |
| `p.parent` | Parent directory |
| `p.is_file()` / `p.is_dir()` | Type check |
| `p.with_name(...)` / `p.with_suffix(...)` | Build a new path |

## Summary

- Traverse with `os.walk` (recursive) or `pathlib.iterdir` (one level)
- Recursive matching: `rglob` / `glob("**/*.ext")`
- Filter with `suffix` or `glob` wildcards
- Don't miss subdirectories
