# 05 Project: Organize the Downloads Folder (Preview, Then Act)

> This lesson ties the first four together into a genuinely usable "Downloads organizer", applying "preview before execute" throughout.

## The Requirement

Bob's `~/Downloads` has 300+ files: PDFs, images, installers, docs all mixed up. Goal: sort by extension into `PDF/`, `Images/`, `Archives/` etc., with unknowns going to `Other/`.

## The Full Script

```python
import shutil
from pathlib import Path

# extension -> folder name
RULES = {
    ".pdf": "PDF",
    ".docx": "Docs", ".doc": "Docs", ".txt": "Docs",
    ".png": "Images", ".jpg": "Images", ".jpeg": "Images", ".gif": "Images",
    ".zip": "Archives", ".rar": "Archives", ".7z": "Archives",
    ".exe": "Installers", ".dmg": "Installers",
}

def plan(root: Path):
    """Return a list of [(src, dst)] move plans"""
    moves = []
    for p in root.iterdir():
        if not p.is_file():
            continue
        ext = p.suffix.lower()
        folder = RULES.get(ext, "Other")
        target = root / folder / p.name
        moves.append((p, target))
    return moves

def run(root: Path, dry_run=True):
    moves = plan(root)
    for src, dst in moves:
        if dry_run:
            print(f"[preview] {src.name} -> {dst.relative_to(root)}")
        else:
            dst.parent.mkdir(parents=True, exist_ok=True)
            if dst.exists():
                print(f"[skip] {dst.name} already exists")
                continue
            shutil.move(str(src), str(dst))
            print(f"[done] {src.name} -> {dst.relative_to(root)}")

if __name__ == "__main__":
    root = Path("~/Downloads").expanduser()
    print("=== pass 1: preview ===")
    run(root, dry_run=True)
    print("=== flip dry_run to False once confirmed ===")
```

## Usage Flow

1. Run `run(root, dry_run=True)` to preview, double-check the buckets
2. Once confirmed, change `dry_run=False` to execute
3. Scan the directory again to see if anything was left behind

## Crash Scene

```python
# Once, treated every entry as a file, including subdirectories:
for p in Path("~/Downloads").expanduser().iterdir():
    shutil.move(str(p), "Other")  # subdirectories got moved into "Other" too!
# Result: every subfolder treated as an "other-class file" crammed into one folder
```

**Consequence**: directory structure wrecked; next run may error out because "Other" already exists. **An organizer must distinguish files from directories** — that's why the script has `if not p.is_file(): continue`.

## Extension Ideas

- Bucket by date (photos by year/month)
- Move the rules into a config file so non-programmers can edit them
- Add a log file recording every move

## Summary

- A real script = plan + preview + execute, three phases
- Use a dict for "extension -> folder" mapping: easy to read, easy to change
- Always filter with `is_file()` to avoid hurting directories
- Dry-run first, then execute
