# 08 Writing Spreadsheets: New Workbook, Writing, Saving

> Done reading — now writing: create a spreadsheet, fill it in, save as .xlsx.

## Creating and Writing

```python
from openpyxl import Workbook

wb = Workbook()            # new workbook
ws = wb.active
ws.title = "Summary"        # rename the sheet

ws["A1"] = "Item"
ws["B1"] = "Qty"
ws["C1"] = "Price"

ws.append(["keyboard", 3, 200])   # append a row
ws.append(["mouse", 5, 80])

wb.save("result.xlsx")
```

`Workbook()` takes no arguments and starts with one empty `Sheet`. `ws.append(row)` is the **easiest way to append a row**; `row` is a list or tuple.

## Batch Writing

```python
headers = ["Item", "Qty", "Price"]
data = [
    ["keyboard", 3, 200],
    ["mouse", 5, 80],
    ["monitor", 2, 1200],
]
ws.append(headers)
for row in data:
    row = list(row) + [row[1] * row[2]]   # add an amount column
    ws.append(row)
```

## Styling (optional)

```python
from openpyxl.styles import Font, PatternFill

ws["A1"].font = Font(bold=True, color="FFFFFF")
ws["A1"].fill = PatternFill("solid", fgColor="4472C4")
```

Styling is the cherry on top. For an automated report, **get the data right first, then make it pretty**.

## Crash Scene

```python
# Forgot to save, or wrong path:
wb = Workbook()
ws = wb.active
ws.append(["a", "b"])
# wb.save("result.xlsx")  <- omitted
# Result: script "finishes", but nothing on disk
```

**Consequence**: the script "succeeds" but no file was created, and you think you're done. **Always save after writing** — the easiest step to forget. Also note: openpyxl **cannot** load a file and save back to the same path overwriting itself; either load, modify, save, or save to a new path.

## Summary

- Create with `Workbook()`, write with `append` or `cell =`
- Always `save("xxx.xlsx")` after writing
- Styling is optional; accurate data comes first
- Don't overwrite the file you're still reading
