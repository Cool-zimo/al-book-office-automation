# 07 Iterating and Summarizing: Sum, Count, Max

> This lesson reads a spreadsheet and runs statistics — summing, counting, finding the max. This is the foundation of automated reporting.

## A Sales Table

Assume this structure (row 1 is the header):

| A(date) | B(item) | C(qty) | D(price) |
|---|---|---|---|
| 2024-01-01 | keyboard | 3 | 200 |
| 2024-01-02 | mouse | 5 | 80 |
| ... | ... | ... | ... |

## Sum and Count

```python
from openpyxl import load_workbook

wb = load_workbook("sales.xlsx")
ws = wb.active

total_qty = 0
total_amount = 0
count = 0
for row in ws.iter_rows(min_row=2, values_only=True):
    if not row[0]:          # skip blank rows
        continue
    _, _, qty, price = row
    total_qty += qty
    total_amount += qty * price
    count += 1

print(f"{count} records, total qty {total_qty}, total £{total_amount}")
```

The core is just **iterate + accumulate** — same as any sum you've written, only the data source changed to a spreadsheet.

## Finding the Maximum

```python
best = None
best_row = None
for row in ws.iter_rows(min_row=2, values_only=True):
    if not row[0]:
        continue
    _, item, qty, price = row
    amount = qty * price
    if best is None or amount > best:
        best = amount
        best_row = (item, qty, price)

print(f"top single sale: {best_row[0]}, amount £{best}")
```

## Crash Scene

```python
# Forgot to skip blank rows, unpacked directly:
for row in ws.iter_rows(min_row=2, values_only=True):
    _, item, qty, price = row
# Error: not enough values to unpack
```

**Consequence**: hits a blank or malformed row and dies with `ValueError`. **Always validate the row first** — `if not row[0]: continue`, or catch the exception. Spreadsheets are a hotbed of dirty data; scripts must be tolerant.

## Grouped Summaries

```python
from collections import defaultdict
agg = defaultdict(lambda: [0, 0])  # item -> [qty, amount]
for row in ws.iter_rows(min_row=2, values_only=True):
    if not row[0]:
        continue
    _, item, qty, price = row
    agg[item][0] += qty
    agg[item][1] += qty * price
```

## Summary

- Summarize = iterate + accumulate / compare
- Skip blank rows first to avoid `ValueError`
- Find max with the classic "start at None, then compare" pattern
- Grouped summaries with `defaultdict`
