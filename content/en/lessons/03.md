# 03 Batch Renaming: String Handling, `Path.rename`, Preview First

> This lesson covers steps 2 and 3: computing the new name, then actually renaming — but **print the plan and confirm before touching anything**.

## Computing the New Name

Renaming is essentially **string transformation**. Turning `report_2024.pdf` into `2024-report.pdf`:

```python
from pathlib import Path

def new_name(p: Path) -> str:
    name, sep, ext = p.stem.rpartition("_")
    if not sep:
        return p.name  # no underscore, keep as is
    return f"{ext}-{name}{p.suffix}"
```

`str.rpartition("_")` cuts from the right, returning `(prefix, sep, suffix)`. Use `rpartition`, not `partition`, to handle filenames like `report_final_2024.pdf` with multiple underscores.

## Actually Renaming

```python
p = Path("report_2024.pdf")
p.rename(p.with_name(new_name(p)))
```

`Path.rename(target)` takes a **full target path**. Using `with_name` keeps the directory and only swaps the filename — safest.

## Preview Before Executing

The most important safety habit of this lesson:

```python
from pathlib import Path

dry_run = True  # run once as True to preview
for p in Path(".").glob("*.pdf"):
    target = p.with_name(new_name(p))
    if dry_run:
        print(f"[preview] {p.name} -> {target.name}")
    else:
        p.rename(target)
```

Run with `dry_run = True` first, see every change. Once it looks right, flip `dry_run` to `False`.

## Crash Scene

```python
# Wanted to add a "bak_" prefix to every file, wrote:
for p in Path(".").iterdir():
    p.rename("bak_" + str(p))
# Might not even error. But you might: overwrite an existing file,
# rename a directory too, or use a wrong path.
```

**Consequence**: data overwritten, script crashes midway, garbage filenames everywhere. **Renaming without a preview is like crossing the street blindfolded.**

## Overwrite Guard

Check whether the target already exists:

```python
if target.exists():
    print(f"skip {p.name}, target exists")
    continue
p.rename(target)
```

## Summary

- Rename = string transform + `Path.rename`
- Use `rpartition` for multiple separators
- Always `dry_run` first
- Check target existence to avoid overwriting
