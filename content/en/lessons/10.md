# 10 Project: Build a Monthly Report (Read Many → Summarize → Output)

> This lesson ties lessons 6–9 together: read multiple detail sheets, summarize by item, output a clean monthly report.

## The Requirement

A directory has `storeA.xlsx` `storeB.xlsx` `storeC.xlsx`, each with structure: item, qty, price. Generate `monthly_report.xlsx`: per-item totals of qty and amount, plus a grand-total row.

## The Full Script

```python
from openpyxl import load_workbook, Workbook
from openpyxl.styles import Font
from pathlib import Path
from collections import defaultdict

def build_report(files, out="monthly_report.xlsx"):
    # 1. aggregate
    agg = defaultdict(lambda: [0, 0.0])   # item -> [total_qty, total_amount]
    for f in files:
        for row in load_workbook(f).active.iter_rows(min_row=2, values_only=True):
            if not row[0]:
                continue
            item, qty, price = row[0], row[1], row[2]
            if item is None:
                continue
            agg[item][0] += qty
            agg[item][1] += qty * price

    # 2. write
    wb = Workbook()
    ws = wb.active
    ws.title = "Monthly Summary"
    ws.append(["Item", "Total Qty", "Total Amount"])
    ws["A1"].font = Font(bold=True)

    grand_qty = 0
    grand_amt = 0.0
    for item, (qty, amt) in sorted(agg.items()):
        ws.append([item, qty, round(amt, 2)])
        grand_qty += qty
        grand_amt += amt

    # grand total row
    ws.append(["Total", grand_qty, round(grand_amt, 2)])
    ws.cell(row=ws.max_row, column=1).font = Font(bold=True)

    wb.save(out)
    print(f"report generated: {out}, {len(agg)} items")

if __name__ == "__main__":
    files = sorted(Path(".").glob("store*.xlsx"))
    build_report(files)
```

## The Three-Phase Structure

1. **Read**: iterate multiple files, load data into a `defaultdict`
2. **Compute**: do the aggregation in memory (cleaner than reading-and-writing at once)
3. **Write**: output in one pass, with a total and styling

## Crash Scene

```python
# Forgot to skip blank rows, so None joined the math:
for row in ws.iter_rows(min_row=2, values_only=True):
    item, qty, price = row
    agg[item][0] += qty
# Error: TypeError: unsupported operand type(s) for +=: 'int' and 'NoneType'
```

**Consequence**: the report crashes halfway, nothing saved. In production, **add type conversion and null guards**: `qty = int(qty or 0)`, `price = float(price or 0)`, and skip when `item is None`.

## Summary

- A real script = read + compute + write, three phases
- Use `defaultdict` for grouped aggregation
- Null guard: `x = int(x or 0)`
- Output a total row and styling for a complete report
