# 04 Sorting by Rules: By Extension/Date, `shutil.move`

> This lesson is about taking scattered files and sorting them into folders by rule — the start of a real Downloads-folder organizer.

## Sort by Extension

Idea: scan the directory, bucket by extension, then `shutil.move` each file into its subfolder.

```python
import shutil
from pathlib import Path

def organize_by_ext(root: Path):
    for p in root.iterdir():
        if not p.is_file():
            continue
        target_dir = root / p.suffix.lstrip(".")  # ./pdf  ./docx
        target_dir.mkdir(exist_ok=True)
        shutil.move(str(p), str(target_dir / p.name))
```

`Path.mkdir(exist_ok=True)` won't error if the directory exists. `shutil.move(src, dst)` takes string paths.

## Sort by Date

Photos and logs are often bucketed by "year/month of modification":

```python
import shutil, os
from pathlib import Path
from datetime import datetime

def organize_by_date(root: Path):
    for p in root.iterdir():
        if not p.is_file():
            continue
        mtime = datetime.fromtimestamp(p.stat().st_mtime)
        target_dir = root / f"{mtime.year}" / f"{mtime.month:02d}"
        target_dir.mkdir(parents=True, exist_ok=True)
        shutil.move(str(p), str(target_dir / p.name))
```

`p.stat().st_mtime` is the modification time as a timestamp (seconds). `parents=True` lets you create multi-level directories in one call.

## Crash Scene

```python
# Wanted to move all .pdf into a pdf folder, wrote:
for p in Path(".").iterdir():
    if p.suffix == ".pdf":
        shutil.move(str(p), "pdf")
# Problem: if "pdf" doesn't exist, shutil.move raises FileNotFoundError
```

**Consequence**: the script errors out halfway — some files moved, others not — leaving the directory in a **half-finished state** that's hard to recover from. Always `mkdir(exist_ok=True)` first.

## A Safer Move

```python
def safe_move(src: Path, dst_dir: Path):
    dst_dir.mkdir(parents=True, exist_ok=True)
    target = dst_dir / src.name
    if target.exists():
        print(f"skip: {target} already exists")
        return
    shutil.move(str(src), str(target))
```

## Summary

- Sorting = compute destination folder + `shutil.move`
- Always `mkdir(exist_ok=True)` before moving
- Use `stat().st_mtime` for date-based sorting
- Check target existence to prevent overwrites
