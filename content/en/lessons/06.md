# 06 Reading Spreadsheets: `openpyxl` Basics, Cells, Rows & Columns

> This lesson enters the world of spreadsheets: opening a workbook with `openpyxl` and understanding the three basic concepts — cell, row, column.

## Opening a Workbook

```python
from openpyxl import load_workbook

wb = load_workbook("sales.xlsx")  # open
ws = wb.active                    # currently active sheet
print(ws.title)                   # sheet name
```

`load_workbook` takes a file path; `wb.active` is the currently active `Worksheet`.

## Reading a Cell

```python
c = ws["B2"]          # by coordinate
print(c.value)        # the cell's value
print(c.row, c.column)

c2 = ws.cell(row=2, column=2)  # by row/col number, 1-based
print(c2.value)
```

Important: rows and columns are **1-based**, not 0. This is the Excel coordinate system.

## Iterating Rows

```python
# iterate every row
for row in ws.iter_rows(min_row=1, max_row=ws.max_row, values_only=True):
    print(row)  # row is a tuple, e.g. (date, item, qty, price)

# iterate a region
for row in ws.iter_rows(min_row=2, min_col=1, max_col=4, values_only=True):
    date, item, qty, price = row
    print(f"{item}: {qty} x {price}")
```

`values_only=True` gives you **values** instead of `Cell` objects — almost always what you want for spreadsheet stats.

## Crash Scene

```python
# Common newbie mistake: treating row numbers as 0-based
ws.cell(row=0, column=0).value
# Error: Row numbers must be 1-based
```

**Consequence**: `ValueError`, script dies. Excel rows start at 1, `(1,1)` is A1. Some people also use `len(ws)` for the row count — wrong: `len` on a worksheet is not the row count; use `ws.max_row`.

## Quick Reference

| Attribute | Meaning |
|---|---|
| `ws.max_row` | Max row number |
| `ws.max_column` | Max column number |
| `ws.dimensions` | Range string, e.g. "A1:D100" |
| `cell.value` | Value (number/string/None) |

## Summary

- Open with `load_workbook`, sheet with `wb.active`
- Row and column numbers start at **1**
- Iterate with `iter_rows(values_only=True)`
- Row count: `ws.max_row`, not `len`
