# 09 Merging Sheets: Combining Many Files into One

> This lesson solves a common need: one sheet per month, then at year end combine all 12 into one — entirely scripted.

## The Requirement

`jan.xlsx` `feb.xlsx` ... all with the same structure (date/item/qty/price). Merge into `year.xlsx`, **with only one header row**.

## The Full Script

```python
from openpyxl import load_workbook, Workbook
from pathlib import Path

def merge(files, out="year.xlsx"):
    out_wb = Workbook()
    out_ws = out_wb.active
    out_ws.title = "Year"
    header_written = False

    for f in files:
        wb = load_workbook(f)
        ws = wb.active
        for i, row in enumerate(ws.iter_rows(values_only=True), start=1):
            if not row[0]:           # skip fully empty rows
                continue
            if i == 1:
                if not header_written:
                    out_ws.append(list(row))
                    header_written = True
                continue              # skip headers in subsequent files
            out_ws.append(list(row))

    out_wb.save(out)
    print(f"merged {len(files)} files, {out_ws.max_row} rows (incl. header)")

if __name__ == "__main__":
    files = sorted(Path(".").glob("*.xlsx"))
    merge(files, out="year.xlsx")
```

## Key Points

1. **Write the header only once**: use a `header_written` flag; first file writes the header, the rest skip
2. **Sort by filename**: `sorted(glob(...))` keeps January before February
3. **Skip blank rows**: guard against dirty data

## Crash Scene

```python
# Wrote every file's header into the merge:
for f in files:
    for row in load_workbook(f).active.iter_rows(values_only=True):
        out_ws.append(list(row))
# Result: a "date/item/qty/price" header pops up every few rows
```

**Consequence**: duplicate headers contaminate the data, so later stats or pivots compute wrong results — and **this kind of error is hard to spot**. Skipping headers after the first file is mandatory.

## Add a Source Column

Sometimes you want to mark which month each row came from:

```python
out_ws.append(list(row) + [f.stem])   # append a source-filename column
```

Now the merged sheet is traceable, handy for verification.

## Summary

- Merging = iterate files + append rows + dedupe headers
- Write the header once, controlled by a flag
- Sort filenames to preserve time order
- Traceability: add a source column
