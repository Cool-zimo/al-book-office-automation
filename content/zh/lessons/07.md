# 07 遍历与统计：求和、计数、找最大值

> 这一节把表格读进来做统计——求和、计数、找最大值，这是报表自动化的地基。

## 一个销售表

假设表结构（第 1 行是表头）：

| A(日期) | B(商品) | C(数量) | D(单价) |
|---|---|---|---|
| 2024-01-01 | 键盘 | 3 | 200 |
| 2024-01-02 | 鼠标 | 5 | 80 |
| ... | ... | ... | ... |

## 求和、计数

```python
from openpyxl import load_workbook

wb = load_workbook("销售表.xlsx")
ws = wb.active

total_qty = 0
total_amount = 0
count = 0
for row in ws.iter_rows(min_row=2, values_only=True):
    if not row[0]:          # 跳过空行
        continue
    _, _, qty, price = row
    total_qty += qty
    total_amount += qty * price
    count += 1

print(f"共 {count} 条记录，总数量 {total_qty}，总金额 {total_amount}¥")
```

核心就是**遍历 + 累加**，和你写过的求和没区别，只是数据源换成了表格。

## 找最大值

```python
best = None
best_row = None
for row in ws.iter_rows(min_row=2, values_only=True):
    if not row[0]:
        continue
    _, item, qty, price = row
    amount = qty * price
    if best is None or amount > best:
        best = amount
        best_row = (item, qty, price)

print(f"最大单笔：{best_row[0]}，金额 {best}¥")
```

## 翻车现场

```python
# 忘了跳过空行，直接解包：
for row in ws.iter_rows(min_row=2, values_only=True):
    _, item, qty, price = row
# 报错：not enough values to unpack
```

**后果**：遇到空行或格式不整齐就 `ValueError` 崩掉。**永远先检查行是否有效**——`if not row[0]: continue`，或者捕获异常。表格是"脏数据"高发地，脚本要容错。

## 分组统计

```python
from collections import defaultdict
agg = defaultdict(lambda: [0, 0])  # 商品 -> [数量, 金额]
for row in ws.iter_rows(min_row=2, values_only=True):
    if not row[0]:
        continue
    _, item, qty, price = row
    agg[item][0] += qty
    agg[item][1] += qty * price
```

## 小结

- 统计 = 遍历 + 累加 / 比较
- 先跳过空行，防 `ValueError`
- 找最值用「先 None 再比较」的经典套路
- 分组统计用 `defaultdict`
