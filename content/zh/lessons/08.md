# 08 写表格：新建工作簿、写入、保存

> 读完了，现在学写：新建一张表、往里填数据、保存成 .xlsx。

## 新建与写入

```python
from openpyxl import Workbook

wb = Workbook()            # 新建工作簿
ws = wb.active
ws.title = "汇总"          # 改表名

ws["A1"] = "商品"
ws["B1"] = "数量"
ws["C1"] = "单价"

ws.append(["键盘", 3, 200])   # 追加一行
ws.append(["鼠标", 5, 80])

wb.save("结果.xlsx")
```

`Workbook()` 不接参数，默认会有一个空的 `Sheet`。`ws.append(row)` 是**追加一行**最方便的办法，`row` 是列表或元组。

## 批量写入

```python
headers = ["商品", "数量", "单价", "金额"]
data = [
    ["键盘", 3, 200],
    ["鼠标", 5, 80],
    ["显示器", 2, 1200],
]
ws.append(headers)
for row in data:
    row = list(row) + [row[1] * row[2]]   # 补一列金额
    ws.append(row)
```

## 设置样式（可选）

```python
from openpyxl.styles import Font, PatternFill

ws["A1"].font = Font(bold=True, color="FFFFFF")
ws["A1"].fill = PatternFill("solid", fgColor="4472C4")
```

样式是锦上添花，自动化报表**先保证数据对，再谈好看**。

## 翻车现场

```python
# 忘记保存，或者路径写错：
wb = Workbook()
ws = wb.active
ws.append(["a", "b"])
# wb.save("结果.xlsx")  ← 漏写了
# 结果：跑完脚本，磁盘上什么都没留下
```

**后果**：脚本"成功"结束，但文件没生成，你还以为搞定了。**写完必须 save**，这是最容易漏的一步。另注意：openpyxl **不能**打开一个文件同时再 save 到同一个路径覆盖自己，正确做法是先 load 改完再 save，或 save 到新路径。

## 小结

- 新建 `Workbook()`，写用 `append` 或 `cell =`
- 写完务必 `save("xxx.xlsx")`
- 样式可选，数据准确优先
- 别覆盖正在读取的原文件
