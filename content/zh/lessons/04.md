# 04 按规则归类：按后缀/日期分文件夹、`shutil.move`

> 这一节讲怎么把散落一地的文件，按规则归到不同文件夹——下载文件夹整理的雏形。

## 按后缀归类

思路：扫一遍目录，按后缀分桶，再把每个文件 `shutil.move` 进对应子目录。

```python
import shutil
from pathlib import Path

def organize_by_ext(root: Path):
    for p in root.iterdir():
        if not p.is_file():
            continue
        target_dir = root / p.suffix.lstrip(".")  # ./pdf  ./docx
        target_dir.mkdir(exist_ok=True)
        shutil.move(str(p), str(target_dir / p.name))
```

`Path.mkdir(exist_ok=True)` 不会因目录已存在而报错。`shutil.move(src, dst)` 接收字符串路径。

## 按日期归类

照片、日志这类文件常用「按修改时间分年/月」：

```python
import shutil, os
from pathlib import Path
from datetime import datetime

def organize_by_date(root: Path):
    for p in root.iterdir():
        if not p.is_file():
            continue
        mtime = datetime.fromtimestamp(p.stat().st_mtime)
        target_dir = root / f"{mtime.year}" / f"{mtime.month:02d}"
        target_dir.mkdir(parents=True, exist_ok=True)
        shutil.move(str(p), str(target_dir / p.name))
```

`p.stat().st_mtime` 是修改时间的时间戳（秒）。`parents=True` 允许一次创建多级目录。

## 翻车现场

```python
# 想移动所有 .pdf 到 pdf 文件夹，写了：
for p in Path(".").iterdir():
    if p.suffix == ".pdf":
        shutil.move(str(p), "pdf")
# 问题：如果 "pdf" 目录不存在，shutil.move 会抛 FileNotFoundError
```

**后果**：脚本跑到一半报错，前面的文件已移动、后面的没动，目录处于**半完成状态**，很难恢复。务必先 `mkdir(exist_ok=True)`。

## 一个更稳的写法

```python
def safe_move(src: Path, dst_dir: Path):
    dst_dir.mkdir(parents=True, exist_ok=True)
    target = dst_dir / src.name
    if target.exists():
        print(f"跳过：{target} 已存在")
        return
    shutil.move(str(src), str(target))
```

## 小结

- 归类 = 计算归属目录 + `shutil.move`
- 移动前务必 `mkdir(exist_ok=True)`
- 用 `stat().st_mtime` 按时间分类
- 检查目标是否已存在，防覆盖
