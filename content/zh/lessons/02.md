# 02 遍历目录：`os.walk` / `pathlib.iterdir`、过滤后缀

> 这一节讲批处理的第 1 步：怎么把一个目录里的文件「找出来」，只挑我们要的那些。

## 两种主流方式

Python 标准库给了两套工具做遍历：老牌的 `os.walk` 和 Python 3.4+ 推荐的 `pathlib`。**建议用 `pathlib`**，它的对象自带各种好用的方法。

### 方式一：`os.walk`（递归）

```python
import os
for root, dirs, files in os.walk("."):
    for name in files:
        print(os.path.join(root, name))
```

`os.walk` 会**递归**进入每个子目录。`root` 是当前目录路径，`files` 是该目录下的文件名列表。

### 方式二：`pathlib`（推荐）

```python
from pathlib import Path
for p in Path(".").iterdir():
    if p.is_file():
        print(p.name, p.suffix)
```

`Path.iterdir()` **只遍历一层**（不递归）。要递归请用 `Path.rglob("*.pdf")` 或 `Path.glob("**/*.pdf")`。

## 过滤后缀

只挑 PDF：

```python
from pathlib import Path
pdfs = [p for p in Path(".").iterdir() if p.suffix == ".pdf"]
# 或者更灵活的匹配
pdfs = list(Path(".").glob("*.pdf"))
```

`glob` 支持通配符，`*.pdf` 匹配当前目录所有 PDF；`**/*.pdf` 递归匹配。

## 翻车现场

```python
# 想遍历所有子目录的 .xlsx，写了：
for p in Path(".").iterdir():
    if p.suffix == ".xlsx":
        print(p)
# 结果：只找到了当前目录下的，子目录里的一个没动
```

**后果**：漏处理文件。因为 `iterdir()` 不递归。要递归请用 `rglob("*.xlsx")`。这是批处理里最常见的 bug——**脚本跑完了，你以为做完了，其实只做了一半**。

## `pathlib` 的常用属性

| 属性/方法 | 作用 |
|---|---|
| `p.name` | 完整文件名 `报告.pdf` |
| `p.stem` | 不带后缀的名字 `报告` |
| `p.suffix` | 后缀 `.pdf` |
| `p.parent` | 父目录 |
| `p.is_file()` / `p.is_dir()` | 判断类型 |
| `p.with_name(...)` / `p.with_suffix(...)` | 生成新路径 |

## 小结

- 遍历用 `os.walk`（递归）或 `pathlib.iterdir`（一层）
- 递归匹配用 `rglob` / `glob("**/*.ext")`
- 过滤用 `suffix` 或 `glob` 通配符
- 别漏掉子目录
