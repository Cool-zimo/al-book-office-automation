# 05 实战：整理下载文件夹（先打印计划，确认后再动）

> 这一节把前三课串起来，写一个真正能用的「下载文件夹整理脚本」，全程贯彻「先预览再执行」。

## 需求

李四的 `~/Downloads` 里堆了 300 多个文件：PDF、图片、安装包、文档混在一起。目标是：按后缀归类到 `PDF/`、`图片/`、`压缩包/` 等子目录，不认识的归到 `其他/`。

## 完整脚本

```python
import shutil
from pathlib import Path

# 后缀 -> 目录名的映射
RULES = {
    ".pdf": "PDF",
    ".docx": "文档", ".doc": "文档", ".txt": "文档",
    ".png": "图片", ".jpg": "图片", ".jpeg": "图片", ".gif": "图片",
    ".zip": "压缩包", ".rar": "压缩包", ".7z": "压缩包",
    ".exe": "安装包", ".dmg": "安装包",
}

def plan(root: Path):
    """返回 [(原路径, 目标路径)] 的计划列表"""
    moves = []
    for p in root.iterdir():
        if not p.is_file():
            continue
        ext = p.suffix.lower()
        folder = RULES.get(ext, "其他")
        target = root / folder / p.name
        moves.append((p, target))
    return moves

def run(root: Path, dry_run=True):
    moves = plan(root)
    for src, dst in moves:
        if dry_run:
            print(f"[预览] {src.name} -> {dst.relative_to(root)}")
        else:
            dst.parent.mkdir(parents=True, exist_ok=True)
            if dst.exists():
                print(f"[跳过] {dst.name} 已存在")
                continue
            shutil.move(str(src), str(dst))
            print(f"[完成] {src.name} -> {dst.relative_to(root)}")

if __name__ == "__main__":
    root = Path("~/Downloads").expanduser()
    print("=== 第 1 遍：预览 ===")
    run(root, dry_run=True)
    print("=== 确认无误后把 dry_run 改为 False 再跑 ===")
```

## 使用流程

1. 先 `run(root, dry_run=True)` 看预览，核对有没有分错桶
2. 确认无误后改 `dry_run=False` 真正执行
3. 跑完再扫一遍目录，看有没有遗留文件

## 翻车现场

```python
# 某次整理，把整个 Downloads 都当文件处理了，包括子目录：
for p in Path("~/Downloads").expanduser().iterdir():
    shutil.move(str(p), "其他")  # 把子目录也移进「其他」里了！
# 结果：所有子文件夹被当成「其他类文件」塞进一个目录
```

**后果**：目录结构被破坏，下次再跑脚本因为「其他」目录已存在可能直接报错。**整理脚本要区分文件和目录**——这也是脚本里 `if not p.is_file(): continue` 的意义。

## 可扩展方向

- 按日期分桶（照片按年/月）
- 把规则抽到配置文件，非程序员也能改
- 加日志文件，记录每次移动

## 小结

- 真实脚本 = 规划 + 预览 + 执行三段式
- 用字典做「后缀→目录」映射，好改易读
- 永远 `is_file()` 过滤，避免误伤目录
- 先 dry-run，再真正执行
