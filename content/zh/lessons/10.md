# 10 实战：生成月度报表（读多个表 → 汇总 → 输出）

> 这一节把第 6~9 课串起来：读多张明细表，按商品汇总，输出成一份漂亮的月度报表。

## 需求

目录下有 `门店A.xlsx` `门店B.xlsx` `门店C.xlsx`，每张表结构：商品、数量、单价。要生成 `月度报表.xlsx`：按商品汇总总数量与总金额，附一个合计行。

## 完整脚本

```python
from openpyxl import load_workbook, Workbook
from openpyxl.styles import Font
from pathlib import Path
from collections import defaultdict

def build_report(files, out="月度报表.xlsx"):
    # 1. 汇总
    agg = defaultdict(lambda: [0, 0.0])   # 商品 -> [总数量, 总金额]
    for f in files:
        for row in load_workbook(f).active.iter_rows(min_row=2, values_only=True):
            if not row[0]:
                continue
            item, qty, price = row[0], row[1], row[2]
            if item is None:
                continue
            agg[item][0] += qty
            agg[item][1] += qty * price

    # 2. 写表
    wb = Workbook()
    ws = wb.active
    ws.title = "月度汇总"
    ws.append(["商品", "总数量", "总金额"])
    ws["A1"].font = Font(bold=True)

    grand_qty = 0
    grand_amt = 0.0
    for item, (qty, amt) in sorted(agg.items()):
        ws.append([item, qty, round(amt, 2)])
        grand_qty += qty
        grand_amt += amt

    # 合计行
    ws.append(["合计", grand_qty, round(grand_amt, 2)])
    ws.cell(row=ws.max_row, column=1).font = Font(bold=True)

    wb.save(out)
    print(f"报表已生成：{out}，共 {len(agg)} 种商品")

if __name__ == "__main__":
    files = sorted(Path(".").glob("门店*.xlsx"))
    build_report(files)
```

## 三段式结构

1. **读**：遍历多文件，把数据装进 `defaultdict`
2. **算**：在内存里完成汇总（比边读边写更清晰）
3. **写**：一次性输出，附合计与样式

## 翻车现场

```python
# 忘了跳过空行，导致 None 参与计算：
for row in ws.iter_rows(min_row=2, values_only=True):
    item, qty, price = row
    agg[item][0] += qty
# 报错：TypeError: unsupported operand type(s) for +=: 'int' and 'NoneType'
```

**后果**：报表生成到一半崩了，文件没保存。生产脚本里要给数据**加类型转换和空值保护**：`qty = int(qty or 0)`、`price = float(price or 0)`，并对 `item is None` 做跳过。

## 输出示例

| 商品 | 总数量 | 总金额 |
|---|---|---|
| 键盘 | 15 | 3000 |
| 鼠标 | 40 | 3200 |
| 显示器 | 6 | 7200 |
| **合计** | **61** | **13400** |

## 小结

- 实战脚本 = 读 + 算 + 写三段式
- 用 `defaultdict` 做分组汇总
- 空值保护：`x = int(x or 0)`
- 输出加合计行和样式，报表才完整
