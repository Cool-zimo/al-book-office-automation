# 06 读表格：`openpyxl` 基础、单元格与行列

> 这一节进入表格世界：用 `openpyxl` 打开工作簿，读懂「单元格、行、列」这三个基本概念。

## 打开工作簿

```python
from openpyxl import load_workbook

wb = load_workbook("销售表.xlsx")   # 打开
ws = wb.active                     # 当前活动表
print(ws.title)                    # 表名
```

`load_workbook` 接收文件路径，`wb.active` 是当前激活的那个 `Worksheet`。

## 读单元格

```python
c = ws["B2"]          # 按坐标取
print(c.value)        # 单元格的值
print(c.row, c.column)

c2 = ws.cell(row=2, column=2)  # 按行号列号取，从 1 开始
print(c2.value)
```

注意：行和列**都是从 1 开始**，不是 0。这是 Excel 的坐标体系。

## 遍历行列

```python
# 遍历所有行
for row in ws.iter_rows(min_row=1, max_row=ws.max_row, values_only=True):
    print(row)  # row 是元组，如 (日期, 商品, 数量, 金额)

# 遍历一个区域
for row in ws.iter_rows(min_row=2, min_col=1, max_col=4, values_only=True):
    date, item, qty, price = row
    print(f"{item}: {qty} x {price}")
```

`values_only=True` 让你拿到**值**而不是 `Cell` 对象，处理表格统计时几乎总是用它。

## 翻车现场

```python
# 新手常犯：把行号当 0 起始
ws.cell(row=0, column=0).value
# 报错：Row numbers must be 1-based
```

**后果**：`ValueError`，脚本中断。Excel 的行号从 1 开始，`(1,1)` 才是 A1。还有人用 `len(ws)` 求行数，那是错的——`len` 作用在 worksheet 上不是行数，要用 `ws.max_row`。

## 常用属性速查

| 属性 | 含义 |
|---|---|
| `ws.max_row` | 最大行号 |
| `ws.max_column` | 最大列号 |
| `ws.dimensions` | 范围字符串，如 "A1:D100" |
| `cell.value` | 值（数字/字符串/None） |

## 小结

- 打开用 `load_workbook`，表用 `wb.active`
- 行号列号从 **1** 开始
- 遍历用 `iter_rows(values_only=True)`
- 行数用 `ws.max_row`，别用 `len`
