# 09 多表合并：把多个文件汇总成一张表

> 这一节解决一个高频需求：每月一张表，年底把 12 张合并成一张——全靠脚本。

## 需求

`一月.xlsx` `二月.xlsx` …… 每张结构一样（日期/商品/数量/单价），要合并成一张「全年.xlsx」，**表头只保留一行**。

## 完整脚本

```python
from openpyxl import load_workbook, Workbook
from pathlib import Path

def merge(files, out="全年.xlsx"):
    out_wb = Workbook()
    out_ws = out_wb.active
    out_ws.title = "全年"
    header_written = False

    for f in files:
        wb = load_workbook(f)
        ws = wb.active
        for i, row in enumerate(ws.iter_rows(values_only=True), start=1):
            if not row[0]:           # 跳过完全空行
                continue
            if i == 1:
                if not header_written:
                    out_ws.append(list(row))
                    header_written = True
                continue              # 跳过后续文件的表头
            out_ws.append(list(row))

    out_wb.save(out)
    print(f"已合并 {len(files)} 个文件，共 {out_ws.max_row} 行（含表头）")

if __name__ == "__main__":
    files = sorted(Path(".").glob("*.xlsx"))
    merge(files, out="全年.xlsx")
```

## 关键点

1. **表头只写一次**：用 `header_written` 标记，第一份文件写表头，后面都跳过
2. **按文件名排序**：`sorted(glob(...))` 保证一月在前、二月在后
3. **跳过空行**：防止脏数据

## 翻车现场

```python
# 合并时把每张表的表头都写进去了：
for f in files:
    for row in load_workbook(f).active.iter_rows(values_only=True):
        out_ws.append(list(row))
# 结果：合并表每隔几行就冒出一个「日期/商品/数量/单价」的表头
```

**后果**：数据表里混着重复的表头行，后续统计或透视会算出错误结果，而且**这种错误不容易被发现**。合并时跳过非首张表的表头，是必须的处理。

## 带来源列

有时需要标记每行来自哪个月：

```python
out_ws.append(list(row) + [f.stem])   # 追加一列来源文件名
```

这样合并后还能追溯数据出处，方便核对。

## 小结

- 合并 = 遍历文件 + 追加行 + 去重表头
- 表头只写一次，用标记位控制
- 文件排序保证时间顺序
- 可追溯性：加一列来源
